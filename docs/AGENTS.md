Important Rules
Publications
Publication information is managed separately using:
業績管理.xlsx

When updating publications:
Preserve the existing HTML structure.
Do NOT redesign the page.
Do NOT change CSS class names.
Do NOT change JavaScript behavior.
Only add, remove, or edit publication entries.

News

Design
Maintain current design.
Do not:
change color themes
change fonts
redesign layout
unless explicitly requested.
File Safety
Before editing:
inspect existing HTML
inspect related CSS
inspect related JavaScript
Never overwrite an entire page unless requested.
Prefer minimal modifications.
GitHub Pages
After modifications:
verify links
verify navigation menu
verify mobile layout
before committing.

Coding Style
Preserve existing coding style.
Avoid large-scale refactoring.
Prioritize stability over modernization.
